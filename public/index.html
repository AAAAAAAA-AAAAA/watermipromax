Wiring

DHT22 — DATA → GPIO 4, VCC → 3.3V, GND → GND
Soil moisture — AO → GPIO 34, VCC → 3.3V, GND → GND
Light (optional) — AO → GPIO 35. Enable LIGHT_SENSOR_ENABLED = true in sketch.

Bare DHT22 needs 10 kΩ pull-up between DATA and 3.3V. ESP32 needs 2.4 GHz Wi-Fi.

Troubleshooting
  • No POST 200: check Wi-Fi name/password (2.4 GHz only)
  • POST 404: plant deleted or server reset — regenerate sketch
  • POST 401: sensor key mismatch
  • Temp/humidity "Not connected": check DHT22 wiring on GPIO 4 + pull-up resistor
  • All sensors drop after ~30s: board stopped — check power/Wi-Fi
